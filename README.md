# My Calculator
A simple calculator web application built with Python and Streamlit.

# Features
Addition
Subtraction
Multiplication
Modulus
Division
Error handling for division and modulus by zero
Simple and interactive user interface

# Technologies Used
Python
Streamlit

# Run the Application
streamlit run app.py

# Usage
Enter the first number.
Enter the second number.
Select a mathematical operation.
Click Calculate to display the result.
